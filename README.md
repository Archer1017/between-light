# Between Light 摄影作品集

采用克制版式的英文摄影展示网站模板。

本仓库保存经过脱敏的源码快照，属于开发原型。

## 功能

- 首页、风景、城市、介绍和联系五页。
- 英文导航、正文、图片说明与交互提示。
- 内容配置与静态页面生成脚本。

## 运行

运行 `python3 scripts/build.py` 从 `content.json` 生成页面，再用 `python3 -m http.server 8000` 本地预览。图片为图库示例，来源见 `assets/photo-sources.json`。
